# AI Macro

AI Macro is a Streamlit research application following the development of the U.S. AI economic boom. It connects investment and financial markets with the development pipeline and business integration. It seeks to understand how the economy is evolving in response to AI integration and how this affects profitability, efficiency, and the labor market. 

The application brings together public company disclosures, market data, government statistics, infrastructure records, and current reporting. It turns those sources into comparable indicators, charts, maps, and written analysis. The AI Macro tab provides the broad view, while the individual research tabs show the underlying developments in each area. Sources, definitions, and calculations are available in the Evidence tab.

## Research areas

- Market and Finance
- Compute, Data Centers, and Connectivity
- Power, Grid & Storage, and Water
- Adoption and Workforce
- Economic Outcomes
- Evidence

## Run locally

Install the project requirements and start the Streamlit application:

```bash
pip install -r requirements.txt
streamlit run ai_macro.py
```
