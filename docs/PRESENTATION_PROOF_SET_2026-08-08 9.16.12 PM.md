# Presentation proof set — 2026-08-08

This review build reconstructs the presentation work that was agreed but not delivered after the chart-width regression repair.

## Design grammar

**Lifecycle outside; proof inside. Briefing first; workbench second.**

Within a domain, the reader should be able to answer the following questions in order without forcing every page into identical geometry:

1. Read — what matters here?
2. State — what is true now?
3. Motion — what is changing?
4. Structure — who, where, or what dominates?
5. Transmission — what converts, validates, or constrains it?
6. Records — can the underlying observations be inspected?

## Protected references

The proof set does not redesign AI Macro, the Regime Board, the Value Realization Bridge, existing signature maps/matrices, the retained-data architecture, or the Streamlit-owned Plotly width contract.

Streamlit remains the sole owner of chart width through `width="stretch"`. Hidden domain tabs are not eagerly rendered.

## Pilot domains

### Market

The page now reads as a market-structure argument rather than a sequence of equally weighted panels:

- Market Read
- Market state and cross-sector signal rail
- Ownership, return contribution, concentration, and participation signature block
- Positioning
- Sector dossier workbench
- One final constituent ledger

### Grid & Storage

The repeated five-section chart-plus-sidecar cadence is replaced with a deliverability sequence:

- Grid & Storage Read
- Five-stage Grid Delivery Pathway: queue scale → project maturity → reliability → storage duration → delivery investment
- Full-width queue-conversion signature view
- Coordinated reliability and storage pair
- Subordinate regional-maturity view
- Delivery-investment history
- One data ledger

### Water

Direct data-center evidence now outranks broad water-system context:

- Water Read
- Exposure state
- Campus Water Exposure Dossier
- Evidence Ladder
- One broader-context workbench with selectable national claims, thermoelectric system, and wastewater investment views
- One data ledger
