# Full-platform presentation rollout summary

This review build propagates the approved presentation grammar from the Market / Grid & Storage / Water proof set across the remaining analytical domains while preserving AI Macro and the Economic Outcomes Value Realization Bridge as protected references.

## Presentation changes

- **Finance:** funding-capacity instrument board → commercial realization → private-capital realization → credit conditions → financial strain → one Finance ledger.
- **Compute:** manufacturing trajectory hero → capacity/demand workbench → serving-economics validation band → critical supply-chain structure → domestic buildout → one Compute ledger.
- **Data Centers:** pulse → Pipeline Explorer hero → geographic concentration → paired connectivity/operator structure → one project ledger.
- **Connectivity:** pulse → Gateway Map hero → interconnection depth → terrestrial expansion → compute/transport mismatch → one Connectivity ledger.
- **Power:** demand/large loads → supply response → generation buildout → price/fuel consequences → one Power ledger. Fuel infrastructure is an alternate view rather than eagerly rendered content.
- **Adoption:** one diffusion-state rail → unified People/Business trajectory canvas → paid-adoption validation → industry breadth → one Adoption ledger.
- **Workforce:** Outcomes Matrix hero → transmission pulse → coordinated employment/labor-flow/compensation/exposure workbench → one Workforce ledger.
- **Economic Outcomes:** protected Value Realization Bridge → national outcome history → paired distribution of gains → investment validation → production context → one Economic Outcomes ledger.

## Space-efficiency rule

A narrow analytical object may not sit alone inside a full-width chapter. Shallow pathway and briefing surfaces are horizontal-first on desktop. The Deliverability Screen now also forces its Streamlit markdown wrapper to occupy full width, preventing the shrink-to-content behavior seen in the local review screenshot.

## Preserved contracts

- Streamlit remains the sole owner of Plotly width via `width="stretch"`.
- Hidden domains do not initialize Plotly charts.
- Alternate analytical views render only the active selection.
- AI Macro, Regime Board, protected signature maps/matrices, dossiers, and Value Realization Bridge are preserved.
- Retained provider data and calculations are unchanged by the presentation rollout.
